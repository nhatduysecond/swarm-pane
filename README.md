# swarm-pane

A Claude Code pane that shows every running subagent with its model, effort and
elapsed time, next to the session's task list.

## Install

```
/plugin marketplace add <owner>/swarm-pane
/plugin install swarm-pane@swarm-pane
```

Then `/swarm` opens the pane.

See [plugins/swarm-pane/README.md](plugins/swarm-pane/README.md) for what it
draws, how it fits a narrow terminal, and the one file it reads.
